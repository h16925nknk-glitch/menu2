# BOYOROU English Menu + 管理画面

## ファイル

- `index.html`：お客様向け英語メニュー
- `admin.html`：メニュー管理画面
- `menu-data.js`：公開メニューデータ
- `app.js`：表示処理
- `style.css`：メニューのデザイン
- `admin.js` / `admin.css`：管理画面

## 管理画面の開き方

VS Codeでフォルダを開き、`admin.html` を右クリックして **Open with Live Server** を選びます。

管理画面では以下ができます。

- カテゴリーの追加・削除
- 料理の追加・削除
- 英語名、産地・注意書き、価格の変更
- 売り切れ表示
- 一時的な非表示
- ブラウザへの下書き保存

## 公開メニューの更新方法

1. `admin.html` で編集する
2. **更新ファイルをダウンロード**を押す
3. `menu-data.js` がダウンロードされる
4. GitHubのリポジトリを開く
5. 既存の `menu-data.js` を開き、右上の鉛筆マークから内容を置き換える、または古いファイルを削除して新しいファイルをアップロードする
6. **Commit changes** を押す
7. 30秒〜2分後、同じQRコードのメニューが更新される

## 重要

この管理画面はGitHub Pagesだけで動く安全な簡易版です。管理画面で編集しただけでは公開ページは自動更新されません。ダウンロードした `menu-data.js` をGitHubへ反映する必要があります。

ログインして「保存」だけで即時更新する本格版には、FirebaseやSupabaseなどのデータベースと認証機能が必要です。
